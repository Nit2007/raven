Gemini Browser Agent Settings

Customize API keys, models, endpoints, and execution parameters

Gemini API Keys

Paste one or more Gemini API keys (one per line). The agent automatically rotates across keys on rate limits or errors. Keys are stored safely in your browser's local storage and never hardcoded or sent to third parties.

Don't have a key? Get one for free at Google AI Studio.

Model Fallback Hierarchy

Specify the Gemini models to use in order of preference (one model ID per line). If a call fails or is rate-limited on the first model, the agent automatically falls back to subsequent models.

Default models: gemini-2.5-flash, gemini-2.0-flash, gemini-1.5-flash
